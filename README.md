## 📌Project Objective:-
The main objective of this project is to analyze network traffic using Wireshark and identify communication patterns, network issues, and potential security threats.

Key objectives:
1. Capture live network packets.
2. Analyze different network protocols.
3. Identify source and destination IP addresses.
4. Monitor TCP and UDP communication.
5. Detect unusual or suspicious network activity.
6. Understand how data is transmitted over a network.


## How Wireshark Works
The basic working process:
1. Capture: Wireshark captures packets from a selected network interface.
2. Filter: Apply filters to find specific network traffic.
3. Analyze: Examine packet headers and protocol information.
4. Inspect: View detailed packet contents.
5. Report: Identify network problems or suspicious activity.

## 🚀 Main Features

Captures network packets in real time from available network interfaces.

### 2. 🔍 Packet Filtering
Filters network traffic using IP addresses, protocols, ports, and other fields.

### 3. 🌐 Protocol Analysis
Examines packet details across different network layers to understand network communication.

### 4. 📊 Network Statistics
Displays network conversations, endpoints, and protocol distribution for traffic analysis.
